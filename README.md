## 📖 Sobre o Plugin
O **RootsSky Battle Pass** é um sistema completo de progressão criado para servidores de Skyblock. Ele permite que os jogadores completem missões diárias, semanais e mensais para ganhar recompensas exclusivas, dinheiro e XP.

O plugin foi desenvolvido pensando em uma experiência limpa e agradavel, sem necessidade de pacotes de textura, funcionando perfeitamente com o visual vanilla do Minecraft.

## ✨ Funcionalidades Principais

### 🎯 Sistema de Missões
- **Missões Diárias:** Resetam a cada 24h (ex: minerar 50 blocos, pescar 15 peixes)
- **Missões Semanais:** Resetam a cada 7 dias (ex: matar 100 mobs, quebrar 1000 blocos)
- **Missões Mensais:** Resetam a cada 30 dias (desafios épicos com grandes recompensas)

### 🎁 Passe de Batalha (100 Níveis)
- **Trilha Gratuita:** Recompensas para todos os jogadores
- **Trilha VIP:** Recompensas exclusivas para jogadores com permissão VIP (multiplicador 1.5x de XP)
- **Progressão Visual:** GUI intuitiva mostrando níveis resgatados, disponíveis e bloqueados

### 🔌 Integrações
- **SuperiorSkyblock2:** Validação de ilha para contagem de missões
- **Vault:** Sistema de economia (recompensas em dinheiro)
- **PlaceholderAPI:** Placeholders para usar em outros plugins

## 🎮 Como Funciona?

### Para Jogadores:
1. Digite `/passe` para abrir o menu do Battle Pass
2. Digite `/passe missoes` para abrir o menu das missoes
3. Complete missões naturalmente jogando (minerando, construindo, pescando)
4. Ganhe XP e suba de nível no passe
5. Resgate recompensas clicando nos níveis disponíveis
6. Use "Resgatar Todas" para pegar todas as recompensas de uma vez!

### Para Administradores:
- `/passeadmin reset <player>` - Reseta o progresso do jogador
- `/passeadmin givevip <player>` - Concede status VIP ao jogador
- `/passeadmin setlevel <player> <nivel>` - Define o nível manualmente

## 📥 Instalação
1. Baixe o arquivo `.jar` mais recente na seção **Releases**
2. Coloque na pasta `plugins/` do seu servidor
3. Reinicie o servidor
4. Pronto! O plugin criará automaticamente os arquivos de configuração

## 🛠️ Requisitos
- **Servidor:** Paper/Spigot 1.21.1+
- **Plugins Recomendados:** 
  - SuperiorSkyblock2 (para missões funcionarem corretamente)
  - Vault + Economy plugin (para recompensas em dinheiro)
  - PlaceholderAPI (opcional)
